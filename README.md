## Harishwa D Reddy

I build whole products, not pieces of them — the database, the service on top of it, and the app
people actually open. Mostly TypeScript, Python and Rust, from Postgres up to phone screens, and
down to firmware on custom boards when a project needs it.

### Things I've built

**[ScoutChem](https://scoutchem.com)** — chemical sourcing that runs itself. A buyer describes what
they need in plain words; it identifies the compound, finds suppliers, emails them, follows the
reply threads and returns ranked quotes. One worker and a database.

**Acadex** — ID card software for schools. Upload a spreadsheet, lay the card out once by dragging
fields where they should sit, print the whole batch from that template.

**[safe-yolo](https://github.com/HARISHWA2003/safe-yolo)** — a Claude Code plugin. With permission
prompts off, it still asks before anything installs software, runs downloaded code, deletes a
directory, or uses sudo. Under 100 lines, no dependencies.
